# #TangGang

Private bachelorette site for the bridesmaids. Three static pages, no build step.

- `index.html` — cover
- `london.html` — London, 13–18 January 2027: map, day-by-day, what to book
- `outfits.html` — bridesmaid dress inspo board, filterable by colour
- `img/` — dress photos

## Put it on GitHub Pages
1. Create a repo (e.g. `tanggang`) and upload everything in this folder to its root.
2. Settings → Pages → Source: *Deploy from a branch*, branch `main`, folder `/ (root)`. Save.
3. It goes live at `https://<your-username>.github.io/tanggang/` in a minute or two.

Pages are marked `noindex`, but a public repo is still public — keep it private if you'd rather, and share the link directly.
